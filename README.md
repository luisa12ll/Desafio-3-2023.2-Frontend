## 💡 Sobre o Projeto

Este é o projeto do **Desafio 3** do processo trainee da EngNet, focado na construção de uma aplicação front-end moderna com **ReactJS**. O objetivo foi criar um quadro Kanban interativo para gerenciar tarefas.

## 🚩 Funcionalidades

- 📝 **Criar Tarefas:** Adiciona novas tarefas em qualquer coluna ("A Fazer", "Fazendo", "Feito") através de um modal.
- ✏️ **Editar Tarefas:** Atualiza tarefas existentes (título, responsável, data e descrição) clicando no ícone de edição.
- 🗑️ **Excluir Tarefas:** Remove tarefas com uma caixa de diálogo de confirmação.
- ➡️ **Mover Tarefas:** Transfere tarefas entre as colunas com botões de ação.

## 🚀 Como Executar o Projeto

1.  **Clone o repositório**
    ```bash
    git clone https://github.com/luisa12ll/Desafio-3-2023.2-Frontend.git
    ```

2.  **Acesse a pasta do projeto**
    ```bash
    cd Desafio-3-2023.2-Frontend
    ```

3.  **Instale as dependências**
    ```bash
    npm install
    ```

4.  **Inicie o servidor de desenvolvimento**
    ```bash
    npm run dev
    ```
